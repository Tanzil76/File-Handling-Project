This project demonstrates core file handling operations in Python — create, read, update, and delete — using the pathlib module for safe path handling. What started as a terminal-based script was rebuilt with a Streamlit front end, adding a sidebar navigation, real-time file browser, and clear success/error feedback for each operation. It's a small but complete example of turning simple backend logic into a usable application.
